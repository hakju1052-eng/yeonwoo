update_unifarm.bat 에 캐시 갱신을 붙이는 예
  @echo off
  set PYTHONIOENCODING=utf-8
  cd /d %USERPROFILE%\Downloads
  echo ===== %date% %time% ===== >> unifarm\_update_console.txt
  python unifarm_collect.py update --workers 6 >> unifarm\_update_console.txt 2>&1
  cd /d %USERPROFILE%\Downloads\unifarm\app
  python -m mushroom_app.etl_cli >> ..\_update_console.txt 2>&1

문제가 생기면
  - "python 을 찾을 수 없습니다": Python 3.10 이상을 설치하고 PATH 에 추가
  - 패키지 오류: cmd 에서  python -m pip install -r mushroom_app\requirements.txt
  - 화면이 비어 있음: build_cache.bat 를 먼저 실행했는지 확인
  - 캐시를 처음부터 다시 만들려면 Downloads\unifarm\app_cache 폴더를 지우고 build_cache.bat

[창 없이 실행하기]
  run_app.bat 는 명령창을 닫으면 앱도 꺼집니다. 창 없이 계속 켜 두려면:
  - start_app.vbs      더블클릭 → 창 없이 백그라운드로 실행 (이미 실행 중이면 알림만)
  - stop_app.bat       실행 중인 앱 종료
  - register_autostart.bat  로그온할 때 자동 시작하도록 작업 스케줄러 등록 (한 번만)
  - 출력·오류 기록: app\app_log.txt
  주의: 메인PC가 꺼지거나 절전에 들어가면 다른 PC에서 접속되지 않습니다.

■ 살균 페이지 (v1.5.0)
  - 살균솥 PC(DESKTOP-ERFRF8M)의 공유폴더 "데이터수집"(.cld 기록)을 mirror_nas.bat 이 Downloads\unifarm\살균솥 으로 복사한다
    (오전·오후 자동 갱신에 포함). 살균솥 PC가 꺼져 있으면 그 항목만 건너뛴다.
  - 폴더 이름이 태그: 살균기N_현재온도(℃) / 살균N현재압력(kPa) / 살균기N_스팀·상부·하부밸브(0/1) / 상한·하한경보·냉각완료·냉각시작(설정값)
  - 앱 캐시: app_cache\retort_1min.parquet·retort_1min_wide.parquet(1분 평균), retort_daily.parquet(일별 요약), retort_cycles.parquet(살균 사이클)
  - 사이클 구분: 배지(105℃ 1차 유지 + 118℃ 2차 유지) / 액탱크(1차 유지 없이 119℃ 2시간 이상) / 이상(중단·미완료).
    2차 유지를 못 끝내고 100℃ 아래로 떨어졌다가 90분 안에 다시 오르면 같은 사이클의 "중단"으로 센다(패킹 불량 등).
  - 사이클 구분: 온도 100℃ 이상 구간 = 한 사이클. 시작 = 스팀밸브 열림, 1차 유지 = 102~109℃, 2차 유지 = 최고온도−1.5℃ 이상,
    냉각완료 = 100℃ 아래로 내려온 시각. F0 = 121.1℃ 기준 누적 살균값(z=10℃).
  - 처음 한 번은 데이터 관리 → "살균솥 기록 읽기" 를 누르거나 refresh_all.bat 을 실행한다.

■ v1.10.1 — 설정습도가 500%로 보이던 문제
